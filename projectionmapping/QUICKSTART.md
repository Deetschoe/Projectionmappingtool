# Quick Start Guide

## Getting Started

1. **Open the application**
   - Simply open `index.html` in your web browser (Chrome or Firefox recommended)
   - You'll need to allow webcam and microphone permissions when prompted

2. **Capture your wall**
   - Click "Capture Wall Photo"
   - Allow webcam access
   - Position your camera to see the wall you want to project onto
   - The photo will be captured automatically

3. **Open projector window**
   - Click "Open Projector Window"
   - This opens a new window that you can move to your projector display
   - Make it fullscreen on the projector (F11 or use the browser's fullscreen option)

4. **Add shapes**
   - Click "Add Rectangle", "Add Circle", or "Add Polygon"
   - Shapes appear in the center of your canvas
   - Click and drag to position them over your wall photo

5. **Map keybinds**
   - Select a shape (click on it)
   - Click in the "Keybind" input field
   - Press any key (e.g., 'A', '1', 'Space')
   - That key will now trigger the shape's effect

6. **Trigger effects**
   - Press the mapped key to trigger the effect
   - Effects include:
     - **Hide/Show**: Toggle shape visibility
     - **Pulse**: Animate with pulsing effect
     - **Color**: Cycle through colors
     - **Flow**: Continuous rotation animation

## Keyboard Shortcuts

- **V** - Selection tool (drag shapes)
- **H** - Hand tool (pan around)
- **Z** - Zoom tool (scroll to zoom in/out)
- **Space** - Play/Pause timeline

## Audio Reactive Mode

1. Toggle "Enable Audio Reactive" checkbox
2. Allow microphone access
3. Shapes will automatically change colors based on audio input
4. The visualizer shows the frequency spectrum

## Tips

- Use **H** (Hand tool) to pan around large canvases
- Use **Z** (Zoom tool) and scroll to zoom in for precise positioning
- Map different keys to different shapes for live performance
- Enable audio mode for automatic reactive visuals during performances
- The projector window updates in real-time as you make changes

## Troubleshooting

- **Webcam not working**: Check browser permissions and make sure no other app is using the camera
- **Projector window not updating**: Make sure pop-ups are allowed and the window isn't blocked
- **Audio not working**: Check microphone permissions in browser settings
- **Shapes not visible**: Check opacity settings and make sure shapes are positioned correctly
